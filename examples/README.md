# Examples

This directory contains small experiments, minimal runnable programs, and scripts that reveal system behavior.

## Organization

Examples are grouped by chapter:

```text
examples/
├── 01-execution/
├── 02-processes/
├── 03-memory/
├── 04-concurrency/
├── 05-networking/
├── 06-storage/
└── 07-distributed/
```

Each example directory contains a `README.md` that defines the question, environment, complete commands, expected behavior, verification method, and cleanup steps. Keep examples small and focused. Continuous implementations that span chapters belong in [`capstone/`](../capstone/).

## Status

The example directories are placeholders that will be filled as the chapters develop.
