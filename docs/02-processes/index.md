# 02 Processes

## Core Question

How does an operating system represent, create, schedule, and reclaim running programs?

## Run It First

Start with the [process example](https://github.com/jingxiang-z/program-to-system/tree/main/examples/02-processes). Observe process lifecycles, system calls, and inter-process communication.

## Learning Objectives

- Understand the boundaries among processes, threads, address spaces, and system calls.
- Explain the basic mechanisms behind context switching, scheduling, and inter-process communication.
- Use operating-system tools to observe a process lifecycle.

## Conceptual Path

- The process model and process lifecycle
- Threads and scheduling
- System calls and the user-kernel boundary
- Pipes, signals, shared memory, and message passing

## Experiment and Evidence

Record process states, system-call traces, complete commands, and the verification process. Content is under development.
