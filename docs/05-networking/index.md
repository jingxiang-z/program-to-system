# 05 Networking

## Core Question

How do applications establish reliable communication over an unreliable network?

## Run It First

Start with the [networking example](https://github.com/jingxiang-z/program-to-system/tree/main/examples/05-networking). Run a minimal TCP client and server and observe the connection behavior.

## Learning Objectives

- Understand the responsibility boundaries among the link, network, transport, and application layers.
- Explain addressing, routing, connection establishment, reliable transport, and congestion control.
- Use basic tools to inspect DNS, TCP, and HTTP interactions.

## Conceptual Path

- Network layering and encapsulation
- IP addressing, routing, and DNS
- TCP, UDP, and reliable transport
- HTTP, proxies, caches, and server models

## Experiment and Evidence

Record packet captures, requests and responses, failure scenarios, complete commands, and verification results. Content is under development.

## Connection to the Capstone

This chapter directly supports the TCP KV server protocol, connection lifecycle, timeouts, and error handling.
