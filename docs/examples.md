# Examples

These examples accompany the seven chapters. Each chapter has one core example and may
include practice examples when a distinct mechanism needs separate treatment, with no
more than three examples per chapter. Every example defines observable behavior,
requirements, tests, and completion criteria in the style of a small systems exercise.

## How to Use the Examples

1. Read the goal and predict the result before running the core example.
2. Implement or complete the requirements and run the automated tests.
3. Save the relevant evidence and write an initial explanation.
4. Revisit the evidence after studying the mechanism.
5. Complete practice examples when additional implementation experience is useful.

All example source files live in the repository's [`examples/`](https://github.com/jingxiang-z/program-to-system/tree/main/examples) directory.
