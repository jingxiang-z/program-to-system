# Examples

These examples accompany the seven chapters. Each one starts with an observable behavior, records the environment, complete commands, expected output, and verification process, and then connects the result to the underlying system mechanism.

## How to Use the Examples

1. Run the minimal example before reading the corresponding chapter.
2. Save the relevant output and write an initial explanation.
3. Revisit the output after studying the mechanism.
4. Change an input, concurrency level, or failure condition to find the boundary of your explanation.

All example source files live in the repository's [`examples/`](https://github.com/jingxiang-z/program-to-system/tree/main/examples) directory.
