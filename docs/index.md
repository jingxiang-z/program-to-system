## Learning Path

| Stage | Topics |
| --- | --- |
| 01–02 | Execution models, processes, threads, and system calls |
| 03–04 | Memory hierarchy, virtual memory, and concurrency control |
| 05–06 | Network protocols, file systems, and persistence |
| 07 | Consistency, replication, and fault tolerance in distributed systems |
| Capstone | In-memory store → TCP service → WAL → multi-node replication and recovery |

The capstone focuses on one replication group. Sharding, cross-region replication, and multi-key transactions are out of scope.
