# 01 Execution

## Core Question

What steps turn source code into instructions running on a processor?

## Run It First

Start with the [execution example](https://github.com/jingxiang-z/program-to-system/tree/main/examples/01-execution). Inspect compilation artifacts, symbols, and a function call before returning here to explain what you observed.

## Learning Objectives

- Distinguish compilation, assembly, linking, loading, and runtime execution.
- Understand the relationships among instructions, registers, the stack, the heap, and calling conventions.
- Use basic tools to inspect executables and observe program execution.

## Conceptual Path

- From source code to an executable: compilation, assembly, and linking
- Instruction sets, registers, and control flow
- Function calls, stack frames, and application binary interfaces
- Loading, dynamic linking, and runtime support

## Experiment and Evidence

Record tool versions, complete commands, relevant output, and an explanation that connects the output to the model. Content is under development.

## Connection to the Capstone

This chapter establishes the foundation for building, debugging, and reasoning about runtime behavior. You will later use it to inspect the KV server executable, execution paths, and performance hotspots.
