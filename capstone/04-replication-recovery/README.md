# 04 Replication and Failure Recovery

## Core Question

How can one replication group preserve consistent data through a node failure and synchronize the node after it recovers?

## Planned Deliverables

- Node roles and a replication protocol for one replication group
- Replication and acknowledgment rules for writes
- Node shutdown, restart, and catch-up behavior
- Fault injection and final-state verification

## Verification
