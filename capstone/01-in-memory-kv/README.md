# 01 In-Memory KV

## Core Question

How can a single process provide a clear, testable key-value store?

## Planned Deliverables

- Basic operations such as `GET`, `SET`, and `DELETE`
- An explicit data model for keys and values
- Unit tests and a minimal command-line entry point
- A concurrent-access policy with correctness tests

## Verification

Document the environment and complete commands. Verify basic semantics, boundary conditions, and concurrent access. Implementation remains to be added.
