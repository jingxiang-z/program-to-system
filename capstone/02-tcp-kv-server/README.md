# 02 TCP KV Server

## Core Question

How can the in-memory store become a network service that remote clients can access?

## Planned Deliverables

- A simple request-response protocol with explicit message boundaries
- A TCP server and minimal client
- Connection lifecycle, timeout, and error handling
- Concurrent multi-client tests

## Verification
