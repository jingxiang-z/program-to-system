# Community Notes

This directory collects reproduction reports, study notes, troubleshooting records, and platform-specific observations.

## Submission Format

Use the following structure:

```text
community/<topic>/<your-note>.md
```

Include:

- The related chapter or example
- Operating system, hardware, and tool versions
- Complete commands that readers can run directly
- Expected results, actual behavior, and verification steps
- Conclusions, workarounds, or unresolved questions
- References and original links

Community notes record individual experience and do not represent the only valid conclusion of the main learning path. Include the date and environment whenever behavior depends on a particular version or platform.
